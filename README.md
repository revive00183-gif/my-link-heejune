# my-link-heejune

개인화된 링크 모음 및 포트폴리오를 제공하기 위한 웹 프로젝트입니다. 
다양한 소셜 미디어 플랫폼과 개인 작업물을 한곳에서 쉽고 깔끔하게 공유할 수 있도록 돕는 직관적인 인터페이스를 목표로 합니다.

## Features

- **중앙화된 링크 관리**: 흩어져 있는 다양한 링크(GitHub, 블로그, 포트폴리오 등)를 하나의 페이지에서 제공.
- **반응형 디자인**: 모바일 및 데스크톱 환경 모두에 최적화된 깔끔한 UI.
- **빠른 성능**: Next.js 프레임워크를 기반으로 구축되어 빠르고 안정적인 사용자 경험 제공.

## Getting Started

프로젝트를 로컬에서 실행하는 방법입니다.

```bash
cd mylink
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속하여 결과를 확인할 수 있습니다.
